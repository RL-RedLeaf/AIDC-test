# 五地集中式数据中心的容量与瓶颈

计算对象是各指定地块在给定工程条件下可持续支撑的 IT 负载，单位为 MW IT。Golden 限定在 ESIF 既有 HPC 模块，其余四处按园区尺度。统一取 2030 年作为假设的建成评估年，采用 2025 全年逐小时天气。各站的用地范围、供电服务规模与建设阶段差异很大，数值反映项目条件，不能直接解释为国家之间的优劣。

| 场址与输入说明 | 基准容量 | 限制资源 | 影响解释的关键证据 |
|---|---:|---|---|
| [美国 Golden](../q1_us_golden/README.md) | 5.66 | 电力 | DOE 工程文件的 6 MW 可用配电功率按设施侧处理；现场 WUE 0.70，按旧冷却系统构造的供水情景为 6.35 m³/h。若保留历史用水总额，水上限降到 1.55 MW IT。 |
| [冰岛 Keflavík](../q1_is_keflavik/README.md) | 100.00 | 电力 | 新变电站已运行的首期 120 MW 假定可持续交付，除以运营方冰岛年度 PUE 1.20。全园区 WUE 和获配供水量仍是情景值。 |

## 模型与边界

计算使用 AIDC-test 提交 `5374865a8234cd5608c243abc99dfe73bdd18493` 的 [原始入口](../../code/run.py)、[核心代码](../../code/immc_power_capacity/core.py)、[正稿与附录 A–C](../../正稿/Q1-v2/IMMC2027-Q1/IMMC2027-Q1.md) 和[用地耦合说明](../../正稿/Q1-v2/IMMC2027-Q1/补充_发电用地与A_e耦合.md)。对每个可投运候选分别取电、水、土地三项上限中的最小值，再在候选中取最大值。各地输入来源、年代、估算步骤及证据性质列入当地 README 与 parameters.json。工程记录另存 site_evidence.csv。

- **基准候选。** 比较电网单供与电网加屋顶光储。屋顶面积仅为技术情景，按与机房共用的投影面积处理，储能占用既有设备空间，新增独占用地取零。并列时可选设备较少的纯电网方案。所有候选的 2030 投运年均为情景设定。
- **太阳能设备。** 用屋面有效阵列面积乘 0.18 kW/m² 得等效额定容量。该密度是例设。水平短波辐照作平铺阵列表面辐照代理；电池片温度近似为环境温度加 (45−20)×辐照/800。性能比 0.85，温度系数 −0.0035/°C，输出裁剪至额定值。充放电额定功率均为光伏容量的 25%，储能时长 4 h，充、放效率分别取 0.90。后三组工程参数参照[仓库 Abilene 算例](../geographic_case_abilene_20261122/10_geographic_case_report.md)。扩展候选的风机与屋顶光伏共用电池，按两者合计装机配储。
- **逐时运行。** 每个时间戳对应 1 小时，储能仅由场内风光充电，全年首尾荷电量相等。可靠增供表示逐小时均能维持的恒定功率，因此可以远小于年均发电功率。另从十年全序列选择总可用光伏出力最小的连续 168 小时，单独循环复算基准两候选。独立周循环和完整十年连续调度的期初电量条件不同。
- **扩展设备。** 可布置地面阵列的四站另计算地面光储与单台小风机加屋顶光储。地面光伏比较两个固定面积并求该分支的连续面积最优。面积可均匀分割、蓄电配置随装机同比例变化，未考虑最小模块与地块形状。燃机另列燃料充足的反事实；土地须先容纳一个完整的 100 MW 模块。气源、风机净空和实际投运许可均待核实。单项候选与明确列入的混合配置之外，还有其他可能的设备组合。
- **水。** 五地统一按现场取水 m³/h 和 L/kWh IT 计算，全年由恒定供水与 WUE 代理设计工况。缺少季节性供水合同时，这会弱化对枯季或热浪的校核。太阳能清洗用水在基准中取零。Aqueduct 数据描述流域压力，保留在每站参数文件中；分配给项目的水量由单独的场址证据或假设给定。
- **土地。** 有效地的数值包含边界假设。若采用整园平均强度且固定设施已包含在分子，就将另列固定用地设为零。冰岛采用紧凑扩建模块的强度外推全园，其约 793 MW 土地单项上限尤其不适合作为可建总容量。Golden 的等效模块面积也不代表全实验室的可用土地。
- **敏感性。** sensitivity.csv 每行都列出变动后的参数。保持光储装机和天气固定时，附录 A 的可靠增供与电网或所配水量无关；用原程序给出的可靠功率重算三项上限，并以原接口另核对变动后的参数组合。图中的瓶颈分区限于基准候选；燃机需另外计算发电取水。
- **验证。** 仓库原测试 53 项通过。核对了五站十年逐时记录连续性、有限数、每个候选的三项最小值与原生 JSON 结果，并对基准供电、取水、用地三项做独立算术对账。供电设计值转为持续交付能力时采用理想可用条件，未计算故障概率或 N−1。

## 图件与复算

每地 fig1_capacity 为三项容量及电网—水量瓶颈分区，fig2_climate 为十年月度辐照和百米风速。每张图有矢量 PDF 和 300 dpi PNG。图2阴影为同一月份十个年度均值的第10–90百分位；2025单年用虚线标识。原始气象位于各站 weather_2016_2025.csv.gz，坐标、网格、归属和接口记录见 parameters.json。数据来自 [ECMWF ERA5，经 Open-Meteo 分发](https://open-meteo.com/en/docs/historical-weather-api)。

在仓库根目录运行单站，或从五份参数及气象数据重新生成全套结果。整套重建会更新生成文件，保留定稿时请在副本中运行。

```bash
python -m pip install -r code/requirements.txt matplotlib
python code/run.py data/q1_cl_quilicura/q1.yaml --json /tmp/quilicura_q1.json
python code/run.py data/q1_cl_quilicura/expanded.yaml --json /tmp/quilicura_expanded.json
python data/q1_five_sites/reproduce.py
python data/q1_five_sites/expanded.py
```

本次运行使用 Python 3.11.15、NumPy 2.4.6、SciPy 1.17.1、PyYAML 6.0.4、Matplotlib 3.11.2。
