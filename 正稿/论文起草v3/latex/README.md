## 编号与引用怎么做的

| 对象 | 做法 |
|---|---|
| 章节 | LaTeX 自动编号（`secnumdepth=4`），`\label{sec:...}` + `\ref{}` |
| 公式 | 每条显示公式 `equation` + `\label{eq:...}`，`\numberwithin{equation}{section}` → 正文 (2.1)…(2.52)，附录 (A.1)…(F.1) |
| 假设 | 自定义 `asum` 环境，**全文连续编号 1–14**，输出“假设 3（配套设施能够输送设计功率）：…”；正文用 `假设~\ref{asum:normal}` 引用 |
| 图 / 表 | 题注自动编号（图 1–4、表 1–2；附录重置为图 F.1、表 F.1–F.4），`\label{fig:...}` + `\ref{}` |
| 引用 | GB/T 7714-2015，上标角标，连续多篇压成 `[13-20]` |
| 定义/注记 | `noteblock` 环境（小字缩进，不编号） |

`\ref`/`\eqref`；现在插删内容不会让引用错位。
