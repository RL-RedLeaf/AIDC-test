# Markdown → LaTeX 转换规范（本工程统一标准）

源文件（只读，勿修改）：`D:\GYH\coding\git\immc-2027\正稿\论文起草v2\论文起草.md`
目标目录：`D:\GYH\coding\git\immc-2027\正稿\论文起草v3\latex\`
编译：xelatex（`ctex` + `fontset=fandol`），主文件 `main.tex`，各章片段在 `sections/`。

**最高原则：内容一字不改。** 只做排版改写（标题层级、公式环境、列表、表格、图、引用标记）。
不允许：改写措辞、补写句子、删除句子、调整语序、修正原文的数据或错别字、给空小节补内容。
原文没有的（摘要、图表说明、结论等）保持空着或按本规范留占位，不许自己编。

## 1. 标题层级

| Markdown | LaTeX | 说明 |
|---|---|---|
| `#` | `\section{...}` | 顶层：引言 / 第一问 / 第二问 / 结果讨论 / 讨论与推广 / 结论 / 附录 A… |
| `##` | `\subsection{...}` | |
| `###` | `\subsubsection{...}` | |
| `####` | `\paragraph{...}` | 段首小标题，后接正文（不需换行命令） |

- 全文 `\setcounter{secnumdepth}{-1}`：**标题不自动编号**。原文标题里自带的编号（`1 能源约束`、`1.1 火力发电`、`4.1 基准校核`、`附录 A`）原样保留在标题文字里，因为正文里大量出现“见第 1–3 节”“4.1 节”“附录 C”“式（C1）”这类交叉引用，改成自动编号会让正文引用失效。
- 标题里 markdown 的转义 `1\.1` / `4\-1` 一律还原为 `1.1` / `4-1`；`**粗体**` 去掉（标题不加粗）。
- 全角空格 `　`（U+3000）保留（原文用它分隔编号与标题），写成普通字符即可。
- 标题中如需 `%`、`&`、`#`、`_`，按第 6 节转义。

## 2. 正文强调与行内代码

- `**文字**` → `\textbf{文字}`；`*文字*` → `\textit{文字}`。
- 连续的碎粗体（`**给定****的****地区**`）合并为一个 `\textbf{给定的地区}`，文字不变。
- `\_`、`\*`、`\.`、`\-`、`\\` 等 markdown 反斜杠转义 → 对应普通字符（`.`、`-`、`_`、`*`）。
- 行内公式 `$...$` → 原样保留 `$...$`（数学内容需按第 3 节修正）。
- 孤立的 `$A$ \> 0`、`$S_{\max}$\<1` 里的 `\>`/`\<` → `>`/`<`。

## 3. 公式

1. Markdown 里独占一行的 `$ ... $`（以及被 `\tag{n}` 标记的块）→ 显示公式：
   ```latex
   \begin{equation}
   ...
   \tag{1}
   \end{equation}
   ```
   原文有 `\tag{...}` 的必须原样保留标签（A1、B2、C1 等也照抄）；原文没有编号的 → 用 `\[ ... \]`（不编号）。**不要自己加编号，也不要改编号。**
2. 公式内部的 unicode 一律转成 LaTeX 命令：
   `η→\eta`, `α→\alpha`, `ρ→\rho`, `λ→\lambda`, `φ→\phi`, `Ω→\Omega`, `Δ→\Delta`, `σ→\sigma`, `𝒯→\mathcal{T}`, `𝒲→\mathcal{W}`, `Σ→\sum`, `≤→\leq`(`\le`), `≥→\geq`(`\ge`), `≈→\approx`, `∈→\in`, `→→\to`, `×→\times`, `·→\cdot`, `±→\pm`, `⌊x⌋→\lfloor x\rfloor`, `−→-`。
3. 中文下标/中文文字放进数学：`P_{风净,t}` → `P_{\text{风净},t}`；`P广域网,ₜ` → `P_{\text{广域网},t}`；`Dⱼ,ₜ` → `D_{j,t}`；`kⱼ,ₜ` → `k_{j,t}`。
4. 字母上划线：`P̄_i` → `\bar{P}_i`。
5. 正文（非公式）中的希腊字母和数学符号也要包进 `$...$`，如 `η是定值` → `$\eta$ 是定值`；`CO₂` → `CO$_2$`，`CH₄` → `CH$_4$`，`N₂O` → `N$_2$O`，`m³` → `m$^3$`，`m²` → `m$^2$`。
6. 已有的 `\text{}`、`\mathrm{}`、`\max`、`\min`、`\sum`、`\frac` 等保持不动；`\mathrm{}` 里的下标 `DC,max` 不用改。
7. `\tag` 只用于 `equation` 环境，不能出现在 `\[ \]` 里。

## 4. 列表

- `1. ...` / `2. ...` → `\begin{enumerate}\item ...\end{enumerate}`
- `- ...` → `\begin{itemize}\item ...\end{itemize}`
- 原文本就用 `1.` `2.` 编号且带**粗体引导句**的，保留 enumerate 即可（编号由 LaTeX 生成，文字不变）。
- 列表项之间原文有空行/段落的，保持一项一项，不要把两段并进同一个 item。

## 5. 引用块（假设/注记）

Markdown 的 `> **假设1 固定场址与建成配置:** 正文...` → 用本工程自定义环境：

```latex
\begin{asum}
\textbf{假设1 固定场址与建成配置：} 正文……
\end{asum}
```

- `asum` 已在 `main.tex` 定义（缩进小字块）。
- 引用块里的多段内容各自成段（空行分段）。
- 原文块引用中多余的空白行、`> ` 空行直接丢弃，不产生空段落。

## 6. 特殊字符转义

正文中这些字符必须转义：`%`→`\%`，`&`→`\&`，`#`→`\#`，`$`（非公式）→`\$`，`_`（非公式下标）→`\_`，`{`/`}`（非公式）→`\{`/`\}`，`~`→`\textasciitilde{}`，`^`→`\textasciicircum{}`，`\`→`\textbackslash{}`。
全角标点（，。；：？！“”‘’（）《》——……）**保持原样，不要转义**。
`–`（en dash）保留原字符；`×`、`·` 见第 3 节。

## 7. 表格

Markdown 表格 → `longtable` + `booktabs`（三线表）：

```latex
\begin{longtable}{@{}p{0.16\textwidth}p{0.3\textwidth}...@{}}
\caption{表 4-1　……}\label{tab:4-1}\\
\toprule
列1 & 列2 & ... \\
\midrule
\endfirsthead
\toprule
列1 & 列2 & ... \\
\midrule
\endhead
\bottomrule
\endlastfoot
内容 & 内容 & ... \\
...
\end{longtable}
```

- 表格标题取自 markdown 表格**上方**那行加粗文字（如 `**表 4\-1　同一电网与供水条件下……。**`），去掉 `**`，`4\-1` 还原为 `4-1`，放进 `\caption{}`。原文没有标题的就不加 `\caption`。
- 表格下方若有 `注：...` 段落，作正文段落排在表后（`\noindent\footnotesize 注：...` 也可，但要保留全部文字）。
- 单元格里的 `$...$` 保留；`|` 分隔符去掉；表头行的 `---` 行丢弃。
- 列宽按内容长短分配，总宽 ≈ `\textwidth`；中文字多的列给宽一点，数字列窄。必要时加 `\small`。
- 表格里不许截断文字，宁可加宽/换行。

## 8. 图

Markdown `![图4\-1\_Abilene8栋容量校核\.png](图片和附件/图4-1_Abilene8栋容量校核.png)` → 

```latex
\begin{figure}[H]
\centering
\includegraphics[width=0.95\textwidth]{figures/fig4-1.png}
\caption{图 4-1　阿比林 8 栋建成范围的资源上限与 $27.06$ MW IT 差额分解。左图……}
\label{fig:4-1}
\end{figure}
```

- 图片文件名映射（已复制到 `figures/`）：
  - `图片和附件/图4-1_Abilene8栋容量校核.png` → `figures/fig4-1.png`
  - `图片和附件/图4-2_四种电源的容量增量.png` → `figures/fig4-2.png`
  - `图片和附件/图4-3_Abilene敏感性与压力测试.png` → `figures/fig4-3.png`
  - `图片和附件/图4-4_四地容量与瓶颈.png` → `figures/fig4-4.png`
  - `图片和附件/F-1_候选地与扩建容量.png` → `figures/figF-1.png`
  - `图片和附件/compute_power_fit.svg` → `figures/compute_power_fit.pdf`（若该 pdf 不存在，则用 `figures/compute_power_fit.png`；两者都没有就保留 TODO 注释并跳过）
- 图题取自图片**下方**那行加粗说明（`**图 4\-1　……**`），去掉 `**`，`4\-1`→`4-1`，放进 `\caption{}`；该加粗说明段落**不要**再作为正文重复一遍。
- 若某图下方没有加粗说明（如 compute_power_fit.svg），就不写 `\caption`，只居中插图。
- `[H]` 需要 `float` 宏包（main.tex 已加载）。

## 9. 引用标记（统一用占位宏，不要自己配文献）

原文用 `\[1\]`、`\[4\-1\]`、`\[L1\]`、`\[7, §5\.2，原式（6）–（13）\]`、`\[2\]\[3\]\[8\]` 这类标记，位置在句子末尾或句中。

统一写成占位宏，**不要写 `\cite{}`，不要猜文献键**：

| 原文 | 写法 |
|---|---|
| `\[1\]` | `\citemark{1}` |
| `\[4\-1\]` | `\citemark{4-1}` |
| `\[L1\]` | `\citemark{L1}` |
| `\[2\]\[3\]\[8\]` | `\citemark{2}\citemark{3}\citemark{8}`（或 `\citemark{2,3,8}`，两者都可） |
| `\[7, §5\.2，原式（6）–（13）\]` | `\citemark{7, §5.2，原式（6）–（13）}` |

`\citemark` 已在 `main.tex` 定义（当前渲染为上标 [..]），最终由 Lead 统一替换为 `\cite{...}`。
标记文字要**逐字照抄**（`4\-1`→`4-1`，`\.`→`.`，方括号去掉，其余保留）。

## 10. 其它

- 原文的空行 → 段落分隔（LaTeX 里就是空行）。连续多个空行合并。
- 原文中形如 `（美国中期选举的例子）` 的括号注记属于正文内容，保留。
- 原稿里明显是写作备注、不是论文正文的句子（例如 `后文式子用的是MW还是kW`）**也要保留**，不许删。
- 数字千分位 `$1{,}100$` 保留 `{,}` 写法。
- 不要加 `\pagebreak`、不要调 `\vspace`，版式交给类文件。
- 每个片段文件开头加一行注释说明来源行号范围，例如 `% source: 论文起草.md L479-L859`。
- 文件用 UTF-8 无 BOM 保存。
