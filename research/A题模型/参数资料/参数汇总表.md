> 口径提醒一：`PUE` 是**设施总功率 / IT 功率**。容量约束用峰值（`η≈1`），电量与水量用均值（`η` 见上），两者不可混用同一符号。
>
> 口径提醒二：负载率跨度从 5% 到 75%，是本表**离散度最大**的参数。企业 GPU 的 5% 与超大规模的 75% 相差 15 倍，直接决定“单位 IT 负载要配多少电”。**必须按设施类型分档，不可取全国或全球平均值。**
>
> 口径提醒三：PUE 法规上限是**合规硬约束**，不是技术参数。建模时应写成 `PUE ≤ PUE_cap(地区)`，而不是取一个典型值。

>
> 口径提醒四：`κ = 0.1–0.3` 是假设值，无公开标准。它是本表最需要做敏感性分析的参数之一。

> 口径提醒一：`CC` 管**峰值**（最糟时刻能不能顶住），`CF` 管**电量**（一年发多少度）。风光卡的是 `CC`，不是 `CF`。
>
> 口径提醒二：**ELCC 不是场站的固有属性，而是相对于系统负荷曲线的边际值。** 同一风场在风电占比 10% 和 40% 的系统里，ELCC 可以差一半以上。引用时必须写明是哪个系统、哪一年的计算结果，不能跨系统移植。
>
> 口径提醒三：ELCC 已隐含“系统有其他资源兜底”。若模型是**孤立站点**（表后自备、无电网支撑），应改用逐时出力保证率，不能用 ELCC。这是最容易混用的一处。

## 六、易错口径清单

| 项目 | 错误做法 | 正确做法 |
|---|---|---|
| 负载率 | 同一 `η` 同时用于容量与水量 | 容量按峰值、电量与水量按均值 |
| 时间折减 | 交付期 7 年、窗口 3 年 → 计 3/7 | 未投运即 0；需平滑则用完工概率 |
| 水量 | 分子分母跨流域混算 | 本地冷却水对本地 `β·R`；异地发电水单列 |
| 土地 | `θ_g·ℓ_g` 直接相乘 | 用装机 `x_g·ℓ_g`，或补 `CF_g` |
| 可再生 | 铭牌容量当可调度容量 | 用 `CC`（峰值）与 `CF`（电量）分开 |
| 购电 | 允许 `P_grid < 0` 悄悄通过 | 显式加弃电变量并约束 |
| PPA | 视为自发电 | 物理上仍占 `A_grid`，只改核算因子 |
| 并网队列 | 队列总容量当可用容量 | 乘建成率（约 13%）或改用已签 IA 容量 |
| ELCC | 跨系统、跨年份移植 | 注明系统与年份；孤立站点改用逐时保证率 |
| PUE 法规 | 取典型值代替 | 写成 `PUE ≤ PUE_cap(地区)` 的硬约束 |
