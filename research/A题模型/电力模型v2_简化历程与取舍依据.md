# 电力承载上限模型 v2：简化历程与取舍依据

## 一、从完整问题到当前模型

最初的因素调查覆盖了电网扩建、输配电、发电技术、燃料与冷却、气象、储能、设备利用率、供电可靠性、环境影响和政策许可。它是一份用于检查遗漏的候选清单。以下整理的是从讨论稿走向 v2 的决策过程；未对一套包含全部因素的模型进行数值消融，因而不把估计的影响百分比写成实测结果。

1. **先确定输出。** 第一问要估计某地可支撑的额定 IT 容量（MW）。年度电量、实际完成的任务数、运行成本和投运日期分别回答其他问题。因此以满载设计能力作为容量口径，年负荷率留给年度电量和足迹核算。
2. **固定研究对象。** 设公共电网保持给定规模，各候选方案均已建成。设备交付期和并网工期决定方案何时可实现；评估具体年份时，只纳入该年前能实际投运的设施。由此可以省去逐年建设变量，并保留题面要求的工期解释。
3. **把公共电网收束到接入点。** 对园区而言，上游发电、已有用户、线路和主变的共同作用体现为持续可交付的有功 MW。若运营商已核算这一额度，可直接引用。只有变电站开放容量时，即使换算了功率因数，也只能作为初筛上界。
4. **改变自建电源的建模尺度。** 土地和设备决定可建装机，地点及机型决定持续净功率。煤、气、风、光保留各自的技术差异，水电限于适宜场址。各技术复用同一功率接口；燃料与冷却等上游细节在能改变交付功率时才展开。
5. **缩小“可靠”的承诺范围。** 基准考察公共电网正常运行，以及所选考察期内真实存在的风光波动。电网故障、孤岛切换和概率停电指标对应另一种服务承诺。稳定供电条款和观测期限定结果的外推范围。
6. **以储能为例检验简化的底线。** 若把光伏和电池都折成一个年均功率，即使白天电量富余、夜间电池已空，模型仍可能误判可以满载。因此正文只用一个光储可靠容量，附录保留充放电、能量守恒和期末恢复期初电量的校核。时间在这里决定当下的静态配置能支撑多少负荷。
7. **保持电、水、土地之间的接口。** 用同工况设施倍率把园区可靠进线功率换成 IT MW。比较最终可持续规模时，每套配置分别求电、水、土地三个上限并取最小，再比较配置。

## 二、各类因素怎样处理

| 因素 | v2 的处理与理由 | 哪些情况需要补回细节 |
|---|---|---|
| 电厂、线路、主变建设与交付时间 | 建成后才可计入供电；工期用来交代上限的实现日期。 | 题目或案例给定投运截止日、分期建设目标。 |
| 区域装机、备用裕度、并网队列与人为分摊系数 | 以项目接入点的交付容量代替上游细节。排队项目容量只提供排队背景；区域备用无法识别园区在哪一条线路受限。 | 缺项目资料但有网架时做节点接入评估；只有宏观数据时报告有依据的区间或上界。 |
| 事故、检修、孤岛、概率缺电指标与备用机 | 将结论限定为正常运行下的容量，备用接替设备不重复增加生产容量。 | 合同允许运营商削减购电，或团队承诺单线退出后仍满载，此时须核对事故额度、持续时间及切换能力。 |
| 园区内部主变、专线与配电 | 假设新建方案按设计功率配足，相关设备计入用地，损耗在相应计量边界计一次。 | 复用有固定上限的现有主变、远端电厂需要借用拥塞的公共通道时，加设共享通道限制。 |
| 煤、气机组、厂用电、气温、燃料物流、冷却降额 | 用“可同时运行的台数 × 当地可持续单机净功率”。气电缺少交付证据时只报供气充足条件下的上界；需要时用电功率除以净效率反推燃料热功率。 | 供气受限、高温明显降低机组能力、取水或排热许可卡住湿冷机组。只允许应急运行的机组不能作为正常主供电源。 |
| 风光选址、气象、设备性能 | 面积与密度决定装机。风电用考察期可靠比例，光伏采用当地出力资料。环保排除、面积口径与机型曲线在取参数时处理。 | 土地共用、风机尾流或地点气象差异显著时，分地块核算。混合方案用同期出力校核；各电源的最差时刻可能不同。 |
| 电池、UPS 储备和任务调度 | 光储保留功率、可用能量、效率及首尾电量条件。应急预留先从可调度能量中扣除。满载能力基准不以推迟任务换取额定 MW。 | 多电源共用储能须联合计算；若服务合同允许短时降载，可另设弹性方案并保持任务量、截止时间和质量一致。 |
| 冷却、配电、GPU 利用率、年度 PUE | 同工况设施功率与 IT 功率之比汇总为满载倍率。设备利用率只在估算运行电量或任务产出时使用。 | 高温同时压低发电和抬高制冷耗电时，在同一时段联合核算。只有年度 PUE 时，将替代值标为近似并做区间分析。 |
| 水、配套电力用地与生命周期足迹 | 配套用地先筛选方案并去重；水和土地负担回到发生地点核算。若缺水直接使电厂少发电，则也要修正电力侧净功率。 | 流域或地块由园区和电厂共享时，保证各模块采用同一份分配。外地电源引起的水和土地影响另计入总足迹。 |
| 成本、电价、碳和排放许可 | 基准目标为可持续 IT 容量；不设经济最优目标。碳排放可单列结果，实际适用的排放、水权、土地和接入许可先用于筛选可行方案。 | 项目存在明确预算或年度、小时排放限制时，直接落实相应约束。一般性净零目标不能直接换算为单站 MW。 |

## 三、怎样验证简化是否可接受

固定配置下记电网交付量为 $G$、自发电可靠增量为 $D$、满载设施倍率为 $k$。由 $P_E=(G+D)/k$ 可得，若只有 $D$ 高估了 $\delta$ MW，则电力上限恰好高估 $\delta/k$ MW。可据此把难以验证的供气或冷却条件换成结论区间。若另有共同通道上限 $C$，则应取 $\min(G+D,C)/k$；只有当 $C\ge G+D$ 时，省去通道约束才不改变容量。前者解释误差如何传递，后者给出省略变量的确切条件。

获得场址数据后，应检查在合理参数范围内，电力上限的量级、最紧资源和方案排序是否改变。排序稳定可以支持战略层面的简化；若排序翻转，应报告切换条件，或恢复对应环节的详细模型。现阶段关于“影响小于 20%”或“删减不改变排名”的判断均有待计算。
