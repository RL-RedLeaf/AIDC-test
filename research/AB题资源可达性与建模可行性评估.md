# IMMC 2027 A/B 题资源可达性与建模可行性评估

核验日期：2026-11-19。目标：辅助选题与规划建模路线。本报告区分资源存在、访问成功、内容适用、可独立验证四个层次；没有将网页可打开等同于模型能够复现。

## 结论

两题均有足够的公开资源完成题目要求，不必购买商业数据或商业求解器。A 的资源分布于数据中心、能源、水资源、土地、计算机系统和公平性研究，获取基础数据相对容易，统一边界和解释承载上限较难。B 的地形分析、洪水演进、泥石流、风险预警形成了较成熟的研究体系，但针对本次事件的流量过程、断面、释放条件等资料仍未核实。

资源多不能直接推导出题目容易。A 的主要风险是能计算却缺少可信的资源预算和公平比较；B 的主要风险是有高级软件却缺少使其输出可信的输入和观测。B 原始 DEM 链接失效已经有公开替代方案，不应继续作为否定 B 的主要理由。

| 维度 | A 题 | B 题 | 对选题的影响 |
|---|---|---|---|
| 基础公开数据 | 较丰富；规模、电源、宏观水压力均有资源 | 较丰富；地形、河网、影像有资源 | 两题都能起步 |
| 核心难得参数 | 地点级可靠供电余量、可分配水量、可开发土地、实际跨站效率 | 洪峰过程、水深断面、初始释放体积、泥石流物性、监测延迟 | 必须设计有依据的情景与敏感性分析 |
| 学术文献积累 | 环境足迹与计算调度丰富，完整覆盖三类资源及普惠性的统一模型需自行构造 | 水力学、泥石流和灾害链研究成熟，跨灾种迁移要谨慎 | B 方法链更连续；A 整合空间更大 |
| 软件与代码 | Python 优化、仿真工具成熟，基础实现门槛较低 | GIS 工具成熟；多相流软件需要更高的专业和配置成本 | A 的程序可能更简单；B 的进阶技术成本更高 |
| 案例与验证 | 多站点规模可比较，但已建规模不等于可持续上限 | 有题面到达时间和类似灾害，但单次事件的约束有限 | 两题均不具备直接、完整的“标准答案” |
| 数据时空一致性 | 年份、地理范围、功率与能耗口径不同 | 历史 DEM、多时相拼接、灾前灾后地形不同 | 均需单独做数据审查 |
| 降级路线 | 代表性地区 + 参数区间 + 调度情景 | 影像量测 + 30 米 DEM + 两种传播时间估计 | 两题都有可交付的简化路线 |
| 提升空间 | 找到集中式/分布式优劣切换条件，并解释资源耦合 | 将地形与速度不确定性转成可执行的预警时间窗 | 提升应来自解释和证据，不能只增加模型复杂度 |

## A：数据资源及其用途

### 已实际核验

1. **Epoch AI 数据中心数据库**
   - 入口：https://epoch.ai/data/ai-data-centers
   - 站点 CSV：https://epoch.ai/data/data_centers/data_centers.csv
   - 时间线 CSV：https://epoch.ai/data/data_centers/data_center_timelines.csv
   - 本次实际读取：站点表 96 行，时间线表 575 行。
   - 站点字段包含名称、功率、H100 等效算力、成本、所有者、国家、地址、信息来源、计算表链接等。
   - 时间线字段包含 IT 功率、设施功率、算力、建设状态、成本、水用量等。`Water use (MGD)` 非空记录为 84 行，涉及 25 个站点。时间线记录不是同步观测样本，不能把该统计解释成严格的站点披露率；也不能将非空数值都当作实测值。
   - 用途：选择案例、核对规模量级、构造同等算力需求、追踪底层来源。
   - 局限：数据库包含估算和规划情景；有设施用水量不代表知道流域可持续可分配水量。

2. **EIA-860 美国发电机组数据**
   - 入口：https://www.eia.gov/electricity/data/eia860/
   - 已核验 ZIP：https://www.eia.gov/electricity/data/eia860/xls/eia8602025.zip
   - ZIP HTTP 200，Content-Length 23,622,347 字节；本次未解包检查全部表格。
   - 数据说明覆盖现有和规划机组、装机、位置、能源类型、部分设备与投产信息。
   - 用途：研究美国案例的电源结构和扩建情景。
   - 局限：区域发电装机不等于某数据中心可获得的可靠接入容量；输电、变电站、既有负荷及调度限制需要另查。

3. **USGS 水文数据**
   - 可访问的现行 API：https://api.waterdata.usgs.gov/ogcapi/v0/collections?f=json
   - 本次已读到连续观测、日值、监测点、峰值、现场测量等集合目录。
   - 用途：所选美国流域的季节变化、枯水情景和站点资料。
   - 局限：需要在选址后检查附近站点、观测变量、记录完整性；流量不能直接全部分配给数据中心，还须考虑既有使用、生态需求和监管条件。

4. **WRI Aqueduct**
   - 入口：https://www.wri.org/data/aqueduct-water-risk-atlas
   - 页面访问成功，说明方法和数据可下载；本次尚未下载全球数据文件。
   - 用途：水压力筛查、代表性地区分类。
   - 局限：风险指标不能直接当作每年可供水的立方米数量。

5. **土地覆盖数据**
   - ESA WorldCover 候选瓦片实际 HTTP 200：
     https://esa-worldcover.s3.eu-central-1.amazonaws.com/v200/2021/map/ESA_WorldCover_10m_2021_v200_N27E084_Map.tif

   - 局限：土地覆盖不等于可建设土地。产权、规划用途、保护区、坡度和配套电网仍需另行约束。

6. **宏观报告与企业披露**
   - IEA：https://www.iea.org/reports/energy-and-ai/executive-summary
   - 题面 UNU 报告链接返回 PDF：https://unu.edu/sites/default/files/2026-10/UNU-INWEH-Report-The_Env_Cost_of_AI-2026.pdf
   - Google 报告入口：https://sustainability.google/stories/
   - 用途：量级、参数范围、术语定义和技术情景。
   - 特别注意：IEA 中 2030 年约 945 TWh 指数据中心整体耗电。题面背景与参考参数中 AI/全部数据中心的口径需要核对，不能把整体数字直接归到 AI 部分。

### 仍需解决的输入

- 目标地点在指定期限内可供给的可靠功率，而非总装机。
- 流域枯水期可持续分配给新设施的水量，以及水权、生态底线。
- 真正可开发的土地面积和发电基础设施的土地边界。
- 跨地域计算的任务适配、额外通信量、能耗、延迟和利用率损失。
- “普惠性”的可度量定义：网络可达不等于可负担的算力服务，也不等于公平受益。

地区选择是 A 的可控优势。可先选择资料较充分的美国案例开展研究，再用其他资源情景讨论推广边界；不能声称已经对全世界得到了同样可靠的上限。

### 适合题目规模的模型路线

基础路线：固定地点、时间范围及技术路线，构造能源/水/土地约束 → 求可行 IT 功率上限 → 对冷却方式与电源组合做情景分析 → 固定有效算力需求，对多个节点分配任务 → 显式比较环境足迹、局部压力、网络损失与服务可及性。

固定技术系数时，可将三个资源上限取最小值作为起点。若冷却方式、电源组合和位置也是决策变量，应在统一约束系统中求解，避免忽略资源之间的耦合。

可实现这一流程的基础编程工具十分成熟。论文的主要工作应放在数据来源、约束定义和优劣切换条件上，无需真正搭建多地算力网络，也无需训练一个大模型。

### 适合题目规模的模型路线

基础路线：影像核对河道 → DEM 提取纵剖面 → 方法一采用有文献依据的平均传播速度区间 → 方法二按地形分段估算传播时间 → 解释与题面 6–7 分钟的差异 → 将偏早到达情景与监测、通信、响应、撤离时间相结合，形成预警规则。

需区分水体平均流速、洪水波传播速度与泥石流前缘速度。不能把稳态均匀清水流条件下的 Manning 公式未经论证地用于整个灾害链。把同一模型重复做一次随机抽样也不自动成为题目要求的第二种估算方法。

进阶路线可加入局部水动力或多相流模拟，但只有新增参数有来源、结果可检验时才值得。8 米 DEM 仍然不能单独决定洪水速度。

| 最常见的错误验证 | 看到现实园区达到某规模，就认定这个规模可持续 | 用 6–7 分钟调好参数，再用同一时间宣称模型被验证 |
| 正确使用已有案例 | 用公开场站做外部量级检查，把承载上限的假设和实际规模分开解释 | 用类似案例解释机制与范围；将目标事件观测作为检验或校准之一，明确角色 |
| 基础计算成本 | 小型优化和情景计算可在普通电脑上完成 | GIS 裁剪和两种简化传播估计可在普通电脑上完成 |
| 可能增加的成本 | 大规模轨迹处理、精细小时电力数据、过多国家的制度和水资源资料 | HMA 拼接下载、GIS 学习、多相流环境部署、大量参数试验 |
| 是否必须付费？ | 基础路线不需要；公司内部数据通常不是付费就能获得 | 基础路线不需要；高分辨率灾后断面/测量可能依赖机构协作 |

本次核验没有运行上述科学模型，也没有全文精读全部论文。文献题录/摘要核验、全文入口访问、代码仓库存在与模型复现是不同完成状态。一次访问失败也不能推导出永久不可达。

## 选题建议与停止扩张范围的条件

若以研究体系成熟、可做图、可以用简化方法完成题目为优先，B 有一定优势；前提是将主线控制在地形、两种时间估计和预警，而不承诺精确复现全过程。至少要先完成一段关键河道的影像核对和纵剖面，确认数据确实支撑研究。

若团队更擅长 Python 优化、文献整合和政策解释，A 也有充足资源，而且案例地点可选择。至少要先选一个资料足够的地点，建立能源、水、土地参数表，标出实测/估计/假设；若无法给可分配资源预算提供依据，应缩小结论范围、使用有依据的区间，而不是虚构精确上限。

实际选题前应做两份小样：A 做一个地点的资源约束表和第一版上限计算；B 做一条源区至目标点的候选路线和第一版纵剖面。比较哪份小样的关键输入更可追溯、哪些结论对假设更稳定，比比较网上资料数量更能预测能否完成一篇可信的论文。
