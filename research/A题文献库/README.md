## 从文献取参数

| 所需参数 | 可用入口 | 要核对的口径 |
|---|---|---|
| 现实园区的 IT MW、建设时点、算力 | [Epoch AI](https://epoch.ai/data/ai-data-centers) | 从时间线区分现状与规划。题面列出的 950 MW、2,263 MW、5 GW 均须统一功率边界才可比较。 |
| 电源装机、燃料及运行信息 | [EIA-860](https://www.eia.gov/electricity/data/eia860/)、[EIA-923](https://www.eia.gov/electricity/data/eia923/) | 装机和发电量可支持电源情景，园区接入能力要另查并网文件、供电协议或供电企业规划。 |
| 流域缺水与枯水期 | [WRI Aqueduct 4.0](https://www.wri.org/data/aqueduct-global-maps-40-data)、[美国 USGS 水文资料](https://api.waterdata.usgs.gov/ogcapi/v0/collections?f=json) | 风险等级可辅助选址。新增可供水量还要结合取水许可、生态底线、既有用量和枯水期。 |
| 代码、任务大小和运行时间 | [Attenni 等的 CaWaLand](https://github.com/GlasgowC3lab/CaWaLand)、[Alibaba Cluster Trace](https://github.com/alibaba/clusterdata)、[MLPerf Training](https://github.com/mlcommons/training_results_v5.0) | 对比任务的质量门槛与完成时限应一致。代码仓库可检索，库内收录的是论文及阅读笔记。 |
| 算力接入与普惠 | [OECD 算力资料](https://oecd.ai/en/compute)、[世界银行互联网使用率](https://data.worldbank.org/indicator/IT.NET.USER.ZS) | 连通性可用于筛查地区。要量化用户获益，另需服务价格、延迟或在时限内得到满足的请求比例。 |

本库以题面指定报告、代表性研究和可落地的方法为线索，核对 Crossref、OpenAlex、期刊、机构仓储及中文政策原件。为比较碳、水、土地三目标，保留了直接研究三种足迹的专题论文。为讨论用户接入，也保留了 OECD 的政策资料。可追溯的新增供电、供水和可建设土地预算仍须按最终案例地点补取。
