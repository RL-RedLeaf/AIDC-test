# A 题第四类因素：政策、碳排放与其他污染

核验日期：2026-11-20。以下为原文**关键内容的中文摘译/归纳**，不是官方译本。角标 `[^Pxx]` 对应文末可打开的本地 PDF、PDF 页序和正式出处；如采用作者稿，正式引用应使用其期刊版。政策的适用地、对象、版本和生效阶段必须随案例地点复核。

## 对照题目后给出的判断

题目第一问明确要求电、水、土地**至少**三类约束，并要求用 IT 设备容量 MW 表示单站上限；背景同时举出 Hyperion 配套燃气发电的 CO₂ 排放。第二问要求比较环境足迹、局地资源压力和公平性；第三问须给 WAICO 提出不超过两项、注明行动者和模型依据的政策建议。故碳和污染应认真计算，但题目没有指定某地块的法定 CO₂ 配额，也没有要求把“政策”与电、水、土地当作同质的第四种物理资源。[^P00]

**建议的定位**：政策是贯穿三种资源与排放的**跨领域可行性条件**。依法适用于所选场址的准入、能效、水权、土地用途、发电/空气排放等规定进入硬约束；排放与其他污染进入环境足迹及局地影响评价；只有找到适用于项目的明确排放总量额度、许可条件，或研究明确设定并解释的碳预算，才计算额外的碳约束上限 `P_C`。不能由“某国承诺碳中和”直接推出 `P_C`。

## 怎样进入第一问的模型

先固定地理位置 `g`、评估时点/运营条件、任务及设备方案 `k`，沿用 [《核心定义01》](../research/A题文献库/核心定义01.md)的 IT 额定容量口径。让 `R(g,k)` 表示项目在该位置、技术方案下能否满足实际适用的规划、环评、接入、水权、能效和污染许可，满足时取 1；一般可写为：

```text
max P_IT
s.t. R(g,k) = 1
     各设计时段的设施用电 <= 可靠可交付供电
     各季节的取水/净耗水 <= 对应许可与安全可分配余量
     园区及配套净占地 <= 合法可开发、符合生态限制的面积
     若确有适用项目的排放总量限额: 年 CO2e <= 该额度
     若确有排污许可/空气质量门槛: 各污染物排放量与受体浓度 <= 各自限值
```

排放模型须保持计量边界一致。一个简化的运营情景为 `C_op = sum_t(E_grid,t × EF_grid,t + E_self,t × EF_self,t + C_other,t)`，其中 `E` 为时段设施用电量、`EF` 为说明是平均还是边际的 tCO₂e/MWh；自备发电的直接排放与购电的间接排放分列，不重复计数。实际 Scope 1/2 披露时还要核对组织边界和 GHG Protocol 的两种范围二口径。工程污染进一步按燃机运行小时、燃料和治理技术估 NOx/PM 等，并在必要时做扩散评价。**热量排到当地空气/水体、污水和噪声**可作定性筛查，找到项目具体标准时再量化。

如果题目选址尚无可核实的项目碳额度，则给出 `P_EWL`（电水地与已查明法定准入的联合可行上限），并报告该容量在不同电源/冷却方案下的**年度排放区间**、单位 IT MW 排放及空气污染筛查；另做一个**明确标为团队设定**的碳预算敏感性情景，计算 `P_C(B)`。在一个固定供电与负载方案、年度排放近似随 `P_IT` 线性变化时可用 `P_C ≈ B / c_k`，但有固定排放、非线性冷却、多个发电方案或限时许可时应直接联合优化，不能机械取四个独立上限的最小值。

**优先级**：现场第一步先过政策和许可的否决性筛查，随后与题目指定的可靠电、水、净可建地一起求容量；碳排放强度、当地空气污染等在技术方案与资源足迹核算时同步评估。对有项目级碳预算或自备机排放许可的地区，碳/污染会成为约束；其他地区不虚构法定配额。评估“政策是否重要”与评估“碳必然是第四个独立 MW 瓶颈”是两个不同的问题。

第二问在**相同任务量、服务质量及统一核算边界**下，分别报告全网 CO₂e、污染发生地和高压力地区的变化；迁移可能降碳而增加当地用水、土地或传输负担。第三问可以据实际瓶颈，建议主管机关发布可交付电力与水资源余量、项目报告用电/取水/排放，或由运营方按许可选择低排放技术。具体建议应由模型算出的案例结果支撑。
